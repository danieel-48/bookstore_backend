| Método | Ruta | Descripción |
|--------|------|-------------|
| POST | `/api/auth/register` | Registra un usuario |
| POST | `/api/auth/login` | Inicia sesión |
| GET | `/api/users/profile` | Consulta el perfil de un usuario |
| GET | `/api/books` | Lista libros y filtra por género o precio |
| GET | `/api/books/search` | Busca libros por título, autor o género |
| GET | `/api/books/{id}` | Consulta el detalle de un libro |
| POST | `/api/cart/items` | Agrega un libro al carrito |
| GET | `/api/cart` | Consulta el carrito de un usuario |
| POST | `/api/purchases` | Compra los libros del carrito |
| GET | `/api/purchases` | Consulta el historial de compras |
